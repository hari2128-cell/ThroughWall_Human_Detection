# Videos

Add demo/presentation videos here, e.g.:

- `live_demo.mp4` — real-time detection demo (screen recording of
  `visualization/Python_GUI/radar_gui.py` or the MATLAB live pipeline,
  ideally alongside a camera view of the physical test setup so viewers can
  see the correlation between motion and the on-screen detection)
- `through_wall_test.mp4` — demonstration through an actual wall/door,
  paired with the `experiments/Different_Walls` results
- `build_walkthrough.mp4` — hardware assembly walkthrough

## Tips for recording a good demo
- Show the static/no-motion baseline first, then introduce motion, so the
  before/after contrast is obvious.
- Keep the radar's field of view and the camera's field of view aligned so
  viewers can see cause (person moving) and effect (detection trace
  spiking) together.
- Keep clips under 2 minutes for placement/interview use — link the full
  raw recording elsewhere if longer.

Large video files may be better hosted externally (YouTube unlisted link,
Google Drive) with just a link/thumbnail committed here, to keep the
repository lightweight.
