# Conference Submission Materials

Tracking folder for conference/workshop submission logistics, separate from
the paper content itself (see `publications/Paper_Draft/`).

## Suggested target venues

For a student/embedded-systems project of this scope, consider:
- University or regional student project/research symposiums
- IEEE student branch conferences
- Maker/hobbyist-adjacent venues (e.g. embedded systems or IoT-focused
  student tracks) if a full academic venue isn't the goal

## Checklist template

- [ ] Identify target conference/symposium and submission deadline
- [ ] Confirm required format (page limit, template — IEEE two-column is
      common) and update `publications/Paper_Draft/` accordingly
- [ ] Prepare camera-ready figures (export clean versions from
      `results/Graphs`, `results/Heatmaps` at publication resolution)
- [ ] Prepare a short demo video if the venue allows supplementary material
      (see `videos/`)
- [ ] Draft abstract (150-250 words) — can reuse
      `docs/Placement_Interview_Summary.md` as a starting point, formalized
- [ ] Submit and track review status/notes here

## Files to add
- [ ] Submission confirmation / reviewer feedback (if applicable)
- [ ] Final camera-ready PDF, once accepted
