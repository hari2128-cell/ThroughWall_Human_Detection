# Poster Outline

For a research/project fair poster (typical A0/A1 portrait layout):

**Header**: Title, your name/affiliation, project logo/photo

**Left column**
- Motivation & Problem Statement (condensed from `docs/Problem_Statement.md`)
- Working Principle (Doppler effect diagram)

**Center column**
- System Architecture block diagram (`docs/Block_Diagrams`)
- Hardware photo(s) (`hardware/Images`, `images/`)
- Signal processing pipeline flowchart (`docs/Flowcharts`)

**Right column**
- Key results: waveform/spectrum/heatmap figures (`results/Graphs`,
  `results/Heatmaps`), accuracy table (`experiments/Accuracy_Evaluation`)
- Future work bullets
- QR code linking to this GitHub repository

**Footer**: Contact info, acknowledgments

Export the final poster here as `Through_Wall_Motion_Detection_Poster.pdf`
(design in PowerPoint, Canva, Illustrator, or similar — A0 300dpi
recommended for print).
