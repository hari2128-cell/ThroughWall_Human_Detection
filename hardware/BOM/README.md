# Bill of Materials (BOM)

`BOM.csv` lists every part used in the prototype with quantity and
approximate cost. Open in Excel/Google Sheets/LibreOffice for a formatted
view.

**Total prototype cost: ~$15-25 USD** — significantly cheaper than
commercial through-wall sensing solutions, which typically use FMCW/UWB
radar front-ends costing hundreds of dollars.

Update this file with your actual supplier links and part numbers once
finalized.
