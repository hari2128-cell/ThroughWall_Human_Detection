# Images

General project images not tied to a specific hardware/results subfolder —
e.g. a hero image for the README, team/setup photos, or diagrams exported
for embedding directly in markdown.

For category-specific images, prefer:
- `hardware/Images/` — physical build photos
- `results/Graphs/`, `results/Heatmaps/`, `results/Screenshots/` — generated
  plots and tool screenshots
- `docs/Block_Diagrams/`, `docs/Flowcharts/` — exported diagram graphics

Use this folder for anything that doesn't fit those categories, e.g. a
banner image referenced at the top of the root `README.md`.
