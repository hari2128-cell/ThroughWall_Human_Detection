# Results

| Folder | Contents |
|---|---|
| `Graphs/` | Waveform/spectrum quick-look plots (real, generated from shipped sample data) |
| `Heatmaps/` | Motion-intensity spectrogram heatmaps (real, generated) |
| `Screenshots/` | Tool/UI screenshots (add your own captures) |
| `Performance_Report/` | Consolidated accuracy/latency/limitations summary |
| `Final_Output/` | Pointers to the best artifacts for demos/submissions |

All figures currently in `Graphs/` and `Heatmaps/` were generated from the
**synthetic** sample recordings in `datasets/Sample_Recordings/` (see that
folder's README for the disclosure) using
`scripts/Visualization/quick_plot.py` and
`visualization/Heatmaps/generate_heatmap.py` respectively — regenerate them
from real hardware captures the same way once available.
